Segue exporter bookmarklet

Export Spotify without Tampermonkey or Violentmonkey. The bookmark runs the same open-source exporter directly on the Spotify web player.

Install

  1. Show your browser’s bookmarks bar.
  2. Drag the button below onto the bookmarks bar.
  3. Open Spotify Web Player, click the bookmark, then use the Segue export button.
